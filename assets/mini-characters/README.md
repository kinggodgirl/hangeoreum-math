# Kenney Mini Characters (3D 하이브리드 아바타) 배치 방법

1. [Kenney Mini Characters](https://kenney.nl/assets/mini-characters) 페이지에서 CC0 에셋 압축 파일을 내려받습니다.
2. 압축을 푼 뒤 아래 두 폴더의 파일을 복사해 넣으면 바로 작동합니다.
   - `Models/GLB format/character-*.glb` → **`assets/mini-characters/glb/`**
   - `Previews/character-*.png` → **`assets/mini-characters/previews/`**

### 기본 연결된 12종 파일 목록
- **기본 무료 (2종)**: `character-female-a` (민지), `character-male-a` (준호)
- **일반 (4종)**: `character-female-b`, `character-male-b`, `character-female-c`, `character-male-c`
- **반짝 (4종)**: `character-female-d`, `character-male-d`, `character-female-e`, `character-male-e`
- **전설 (2종)**: `character-female-f`, `character-male-f`
