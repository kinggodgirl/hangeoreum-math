## 1. 설계 원칙: 교과서 문제에서 거꾸로

1. 차시의 도착점은 **교과서 문제**예요. 차시를 만들 때는 `유형-분석.md`의 그 차시 유형표에서 시작해요.
2. 유형표 한 줄(`type`)이 **유형 익히기 한 묶음**이 돼요. 같이 풀기와 혼자 풀기를 함께 묶어요.
3. 학생 화면에 내는 문제는 교과서 문제의 **쌍둥이**예요. 수치나 상황을 바꾸고, 원문은 쓰지 않아요.
4. 걸음(🌱·🌿·🌳)은 학생이 고를 수 있어요(지금처럼). 고정된 반이 아니라 올라가는 길이에요.

## 2. 세 걸음의 목표와 다 했다는 기준

| 걸음 | 목표 | 다루는 문제 | 도움 | 다 했다는 기준 |
| :--- | :--- | :--- | :--- | :--- |
| 🌱 첫걸음 | ① 개념의 사례·비사례를 가려냄 ② 기본 유형을 설명하는 교사 지시를 이해하고 따라 함 | 사례·비사례 + `cat: basic` 유형 | 많음: 풀이된 예제 → 빈칸 채우기 → 혼자 하기. 계산은 교사 대행 가능 | 사례·비사례 통과 + 기본 유형마다 **도움 없이 쌍둥이 1문제** 해결 |
| 🌿 한걸음 | 교과서 **기본 유형 숙달** + 자주 나오는 복합 4가지 | `cat: basic` 전체 + 아래 3절 복합 | 대표 예제(필요할 때만) | 유형별 쌍둥이를 맞히고, **다음 날 [복습 추천]도 통과**(이틀 연속) |
| 🌳 두걸음 | **모든 교과서 시험형 문제** 극복 | `basic` + `comp` + `app` (탐구 활동은 빼요) | 적음: 복합은 "어떤 기본 두 개?" 먼저 고르기 | 차시 마무리(유형 섞기) 통과 + 복습 추천 통과 |

- 첫걸음과 한걸음은 **같은 기본 유형**을 다뤄요. 다른 건 도움의 양이에요.
- 첫걸음의 "따라 하기"가 흉내로 끝나지 않게, 마지막에 **도움 없는 1문제**를 꼭 둬요.
- 두걸음의 복합 문제는 먼저 **"이 문제는 기본 유형 무엇 + 무엇?"**을 고르고(분해), 그다음 풀어요. 예: 색칠한 부분 = 부채꼴 넓이 + 빼기.
- 두걸음 범위에서 빼는 탐구 활동: 공학 도구 관찰, 생활 속 예 찾기 같은 `kind: open|more|world|explore` 중 `form: explain`인 것. 이런 활동은 개념 보기 탭에서 써요.

## 3. 한걸음에 넣는 "자주 나오는 복합" 4가지

교과서에 여러 번 나오고 점검·마무리에도 나오는 복합만 한걸음 끝에 넣어요. 나머지 복합(도형 성질 결합, 회전체 단면 넓이 등)은 두걸음에 남겨요.

| 복합 유형 | 꼬리표 `type` | 교과서 문항 수 | 기본 두 개로 나누면 |
| :--- | :--- | ---: | :--- |
| 색칠한 부분 둘레·넓이 | `sector:shade` | 7 | 부채꼴 호·넓이 + 더하기/빼기 |
| 뿔대 겉넓이·부피 | `conearea:frust`, `cone:frust` | 4 | 큰 뿔 − 작은 뿔 (뿔 공식 두 번 + 빼기) |
| 비로 중심각 나누기 | `cent:ratio` | 3 | 비의 합 → 360° × (내 몫 / 합) |
| 잘라 낸 입체 | `area:comp`, `volume:comp` | 3 | 큰 입체 − 잘라 낸 입체 (겉넓이는 "잘라도 같은 면" 함정) |

해당 차시(`sector`, `cent`, `area`·`volume`, `conearea`·`cone`)의 한걸음 유형 목록 **맨 끝**에 한 묶음씩 둬요.

## 4. 차시 마무리

- 지금처럼 **유형을 섞어서** 풀어요(인터리빙). 한 유형만 몰아 풀면 시험에서 무슨 유형인지 알아보지 못해요.
- 마무리 문제는 그 걸음이 다루는 유형에서 골고루 뽑은 쌍둥이 문제예요.
- 마무리에서 틀린 유형은 **복습 추천에 먼저** 올려요(5절).

## 5. [복습 추천] — 이틀 연속 숙달 확인

기초 연산의 "다음 복습 날짜" 방식(`js/05-calc.js`의 `box`·`due`, `BOX_DAYS=[0,1,2,4,7,14]`)을 **차시 유형**에도 똑같이 써요.

### 학생이 보는 흐름
1. 오늘 어떤 유형을 마치면(혼자 풀기 또는 차시 마무리에서 맞힘), 그 유형의 다음 복습 날짜가 **다음 날**로 잡혀요.
2. 다음 날 홈 화면에 카드가 떠요: **`[복습 추천] 어제 익힌 유형 3문제 · 2분`**
3. 쌍둥이 3문제(숫자를 바꾼 문제)를 풀어요.
   - **3문제 다 맞힘**: 그 유형에 **숙달 ✓**가 붙어요(이틀 연속 성공). 다음 복습은 3일 뒤, 그다음은 7일 뒤예요. 한 문제씩만 가볍게 나와요.
   - **틀림**: 그 유형의 대표 예제를 한 번 보고, 다음 날 다시 추천해요(상자 1로 돌아감).
4. 보상은 작게 **+2포인트**(하루 1번)예요. 숙달 ✓은 차시 진도에 남아요.

### 부담 줄이기 규칙
- 하루 **최대 3문제**예요. 복습할 유형이 많으면 날짜가 가장 오래된 것부터, 마무리에서 틀린 유형을 먼저 골라요.
- 카드는 "오늘의 길잡이"와 같은 자리에 하나만 떠요. 닫으면 그날은 다시 안 떠요.
- 시험 1주 전에는 숙달 ✓ 유형도 한 번씩 다시 섞어 추천해요(선택 기능).

### 저장 제안 (구현 때 확정)
- 차시 진도(`DB[lessonId]`) 안에 유형별 칸: `rev[type] = { box, due, ok }`
  - `box` 0~5, `due` YYYY-MM-DD, `ok` 숙달 ✓ 날짜(한 번 붙으면 지우지 않음)
- 기기 병합이 큰 값 우선이라 `ok`는 날짜 문자열로 늘어나기만 하게 저장해요(T05 Got/Used와 같은 원리).
- 교사 화면에는 차시별 "숙달 ✓ 유형 수 / 전체 유형 수"를 보여 주면 좋아요(별도 작업).
