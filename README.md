# 한 걸음 수학 — 설치와 로그인 설정 안내

학생용 사이트(GitHub Pages)와 학습 기록 서버(Supabase, 무료)를 연결하는 방법입니다.
서버를 연결하지 않아도 사이트는 **체험 모드**로 동작해요. (로그인·교사 화면이 그 기기 안에서만 흉내 내며 동작)

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 전체 (한 장짜리) |
| `config.js` | 서버 주소와 공개 키 두 줄. 비워 두면 체험 모드 |
| `labs/polyhedron-lab.html` | 「입체도형 탐구」 복사본 |
| `supabase/schema.sql` | 서버에 한 번 붙여 넣어 실행하는 설정 (새로 설치할 때, 게임 설정 포함) |
| `supabase/game.sql` | 이미 설치한 서버에 게임(보스전·숫자야구) 설정만 추가할 때 |
| `icons/`, `manifest.webmanifest` | 패드 홈 화면 아이콘 |

## 1. Supabase 서버 만들기 (약 10분, 한 번만)

1. https://supabase.com 에 가입하고 **New project** 를 누릅니다.
   - Region: **Northeast Asia (Seoul)**
   - Database password: 아무 긴 비밀번호 (따로 쓸 일은 거의 없지만 적어 두세요)
2. 왼쪽 메뉴 **SQL Editor** → **New query** → `supabase/schema.sql` 내용을 모두 붙여 넣고 **Run**.
3. 같은 창에서 아래 한 줄을 실행해 **교사 비밀번호**를 정합니다. (따옴표 안을 바꾸세요)
   ```sql
   select public.hg_setup_teacher('여기에-교사-비밀번호');
   ```
4. **Project Settings → API** 에서 두 값을 복사합니다.
   - Project URL (예: `https://abcdefghijkl.supabase.co`)
   - `anon` `public` 키 (긴 글자)

> anon 키는 공개되어도 괜찮은 키예요. 모든 표는 잠가 두었고, 정해 둔 기능(로그인, 내 기록 저장 등)만 열려 있어요.
> **service_role 키는 절대 config.js에 넣지 마세요.**

## 2. config.js 채우기

```js
window.HG_CONFIG = {
  supabaseUrl: 'https://abcdefghijkl.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...'
};
```

## 3. GitHub Pages에 올리기

1. GitHub에서 새 저장소(예: `hangeoreum-math`)를 만들고 위 파일들을 그대로 올립니다.
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
3. 1~2분 뒤 `https://<아이디>.github.io/hangeoreum-math/` 로 열립니다.

## 4. 학생 번호 만들기

1. 사이트 맨 아래 **교사 화면** → 교사 비밀번호로 로그인.
2. **학생 만들기**에서 학년·반·번호 범위를 정해 **만들기**.
3. 비밀번호(4자리)는 이때 **한 번만** 보여요. **목록 복사**(엑셀에 붙여 넣기) 또는 **카드로 보기 → 인쇄**.
4. 비밀번호를 잊은 학생은 표의 **비밀번호** 버튼으로 새로 만들어 주세요. (그 학생의 다른 기기 로그인도 끝나요)

## 학생은 이렇게 써요

학년·반·번호를 고르고 비밀번호 4자리를 누르면 끝. 다른 기기에서 로그인해도 진도·포인트·복습 노트가 이어져요.
**학교 패드처럼 함께 쓰는 기기는 공부를 마치면 로그아웃** (내 기록 화면 또는 오른쪽 위 이름 → 로그아웃).
로그인하지 않으면 예전처럼 그 기기에만 기록이 남아요.

## 차시 흐름 (선행 + 다지기, 2주 순환)
한걸음 수학은 **다음 주 정규 수업 내용을 미리** 다루고, 정규 수업이 끝나면 다시 다져요.
1. **미리 보기** (정규 수업 전에): 핵심 낱말 · 그림 · 쉬운 예시
2. **같이 풀기** (정규 수업 뒤에): 한 단계씩 맞히며 풀기
3. **혼자 풀기**: 5문제 이상. 지난 차시 문제가 열에 셋쯤 **섞여** 나와요(섞어 풀기). 섞인 문제를 틀리면 그 차시 복습 노트로 가요.
4. **더 알아보기**: 탐구 활동. 정규 수업의 발견 장면을 먼저 보지 않도록 수업 뒤에 하도록 안내해요.

저장되는 진도 이름(concept · steps · practice · explore)은 예전 그대로라 학생 기록은 그대로 이어져요.

## 오늘의 길잡이 (집에서 혼자 할 때)
- 처음 화면 맨 위에서 오늘 할 일을 순서대로 보여 줘요: ① 복습할 문제가 있으면 복습 → ② 지금 차시의 다음 할 일(개념 → 탐구 → 단계 문제 → 연습 5문제) → ③ 그 차시에 필요한 기초 연산 → ④ 오늘의 계산
- 한 번이라도 공부한 학생은 첫 화면의 큰 그림을 줄이고, 준비 중인 단원은 한 줄로 모아서 휴대폰에서 덜 내려도 되게 했어요.
- 교사 화면 학급 현황 위에 **챙겨 볼 학생**: 7일 넘게 안 들어온 학생, 복습이 5문제 넘게 밀린 학생, 기초 연산을 시작하지 않은 학생

## 기초 연산 (서버 설정 필요 없음)

기초학력 학생을 위해 학습과학 근거로 설계했어요. 주제는 15가지예요.

| 묶음 | 주제 |
|---|---|
| 기초 다지기 | 덧셈·뺄셈, 곱셈구구, 나눗셈, 계산 순서, 분수의 뜻, 어림하기 |
| 입체도형에서 쓰는 계산 | 곱셈 감각, 제곱수·세제곱수, 식에 수 넣기, 거꾸로 풀기, 넓이 공식, π가 있는 계산, 분수 곱하기, 겉넓이 더하기, 단위 바꾸기 |

학생이 하는 순서
1. **시작점 찾기** (처음 한 번, 10문제): 맞았는지는 하나씩 알려 주지 않고, 끝나고 "여기부터 해요" 추천 순서를 보여 줘요. '모르겠어요'를 누를 수 있어요.
2. **핵심 낱말** (주제마다 하나): 계산을 보면 무엇을 떠올릴지 "신호 → 낱말 → 그림 → 식"으로 이어 줘요. 예) ⅓ ×처럼 분수가 곱해져 있으면 → 💡 묶음 → 12개를 3묶음 중 1묶음 → ⅓ × 12 = 12 ÷ 3. '낱말 잇기' 3~4문제(그림 ↔ 식, 식 ↔ 말, 낱말 ↔ 계산)로 확인해요.
   연습 1단계에서는 문제 위에 💡 떠올릴 낱말이 보이고, 2·3단계와 오늘의 계산에서는 먼저 떠올려 보고 막히면 눌러서 봐요. 틀리면 낱말과 뜻이 다시 나오고, 오늘의 계산에는 '이 계산에 떠올릴 낱말은?' 문제가 끼어 있어요(점수에는 안 들어가요).
3. **생각하는 법** (주제마다 2~4개): 보기(예시 + 생각 질문) → 같이(앞 단계는 채워 둔 문제) → 혼자(그림 없이). 10칸 틀, 십 막대, 수직선, 점 배열, 묶음, 막대, 넓이 모형 같은 그림을 써요. 🔊 읽어 주기가 있어요.
4. **연습** (3단계 × 10문제): 틀리면 실수에 맞는 피드백(예: "앞에서부터 차례로 계산했어요. 곱셈을 먼저 해요") → 쪼개서 같이 풀기 → 끝에 비슷한 문제로 한 번 더. 언제든 '쪼개서 풀기'를 누를 수 있고, 두 문제 연속으로 틀리면 도움을 제안해요. 처음에 8문제 이상 맞히면 별.
5. **오늘의 계산** (10문제): 복습할 때가 된 주제(1·2·4·7·14일 간격) + 곱셈구구 + 지난 주제를 섞어서 내요. 시간 재기는 기본으로 꺼져 있어요.

곱셈구구는 따로 **구구단 표**(36칸, 순서를 바꿔도 같으니까)로 관리해요. 모르는 칸은 연습 중에 간격을 두고 두 번 더 나오고, 빠르고 정확하게 맞힌 날이 다른 날 두 번 쌓이면 '익힘'이 돼요. 시간은 학생에게 보이지 않아요.

교사 화면의 기초 연산 칸에 별과 구구단 익힘 칸 수가 함께 나오고, 엑셀에는 '구구단 익힘'과 '기초 연산 시작점(추천 순서)'이 들어가요. 시작점 찾기에서 덧셈·뺄셈이나 곱셈구구부터 다지기로 나온 학생은 '챙겨 볼 학생'에 따로 모여요.

설계 근거: 미국 교육부 IES 실천 지침 「Assisting Students Struggling with Mathematics」(2021, 초등; 2009, 초·중등)의 체계적·명시적 지도, 구체물·그림 표현, 수직선, 기본 연산 유창성, 누적 복습 권고와 인출 연습·간격 반복·섞어 풀기·예시 학습(점진적 철회)·멀티미디어 학습 연구. '학습 유형별 맞춤' 같은 신경 신화는 넣지 않았어요.

## 게임 요소

### 이미 서버를 설치했다면: 게임 설정 한 번 추가하기
1. Supabase 대시보드 → **SQL Editor** → **New query**
2. `supabase/game.sql` 내용을 모두 붙여 넣고 **Run** → "Success"가 나오면 끝
3. 여러 번 실행해도 괜찮고, 학생 기록은 그대로 남아요. 실행하기 전에는 보스전 자리에 "선생님이 서버에 게임 설정을 추가하면 열려요"라고만 나오고, 그동안 받은 포인트는 학생 기기에 모아 두었다가(최근 3일치) 설정 후 올라가요.

### 오늘의 미션 (서버 설정 없이도 동작)
- 날마다 미션 3개: 가벼운 것(용어 카드 3개 열기 / 오늘의 계산) · 중심(단계 문제 1개 / 연습 3개) · 도전(탐구 활동, 안 틀리고 2개 맞히기, 계산 8개 이상, 복습 등)
- 하나에 +3, 셋 다 하면 보너스 +10, 며칠 연속으로 했는지 표시

### 꾸미기 상점 (서버 설정 없이도 동작)
- 포인트로 내 캐릭터(정다면체 몸 모양 · 색 · 눈 · 모자)와 사이트의 형광펜 색을 바꿔요.
- 물건을 사도 **모은 포인트(교사 화면의 포인트)는 줄지 않아요.** "쓸 수 있는 포인트 = 모은 포인트 − 쓴 포인트"예요.

### 우리 반 보스전 (game.sql 필요)
- 학생이 받은 포인트만큼 같은 반 보스에게 데미지가 들어가요. 보스는 매주 월요일에 새로 나타나요.
- 1단계 보스 체력 = **학생 1명당 체력 × 반 학생 수**(최소 5명). 한 마리를 물리치면 다음 단계 보스가 나오고 체력은 1.5배, 2배…로 늘어나요(한 주 최대 6마리).
- 학생 화면에는 **개인 순위가 없어요.** 반 전체 데미지, 참여한 친구 수(예: 17/20명), 내가 준 데미지만 보여요.
- 우리 반이 보스를 물리치면, 그 주에 한 번이라도 데미지를 준 학생 모두 보너스 포인트(+10, 단계마다 +5씩 더)를 받아요.
- 교사 화면 → 반을 고르면 **우리 반 보스전** 칸이 보여요: 학생 1명당 체력 바꾸기(기본 50), 아직 참여하지 않은 번호, **크게 띄우기**(수업 화면용, 8초마다 자동 갱신, 전체 화면 버튼).
- 점수 부풀리기 방지: 한 번에 200, 하루 500포인트까지만 데미지로 쌓여요.

### 숫자야구 (친구와 대결은 game.sql 필요 · 컴퓨터와 연습은 설정 없이 가능)
- 처음 화면의 **숫자야구** 띠 → 방 만들기 → 방 번호 4자리를 친구에게 알려 주면, 친구가 「방 번호로 들어가기」에서 번호를 눌러 1:1로 대결해요. 우리 반 열린 방 목록에서 바로 들어갈 수도 있어요.
- 규칙: 1~9 중 서로 다른 숫자 3개(어려움은 4개)로 비밀 숫자를 정하고, 번갈아 상대 숫자를 추리해요(스트라이크·볼·아웃). 방장이 먼저 하고, 방장이 맞혀도 상대에게 같은 횟수만큼 기회가 있어서 둘 다 맞히면 비겨요. 한 번에 90초, 두 번 연속 시간을 넘기면 져요. 15번까지.
- 판돈: 친선(0) · 5 · 10 · 20 · 50 중에서 골라요. 이기면 건 포인트의 2배를 받고, 지면 잃고, 비기면 돌려받아요. **오가는 건 ‘쓸 수 있는 포인트’뿐이라, 모은 포인트 기록과 보스 데미지는 바뀌지 않아요.**
- 속이기 방지: 비밀 숫자는 서버에만 있고 경기가 끝나야 상대에게 보여요. 스트라이크·볼도 서버가 계산해요. 한 학생당 하루 10판까지.
- 화면에 **추론 메모**(1~9를 눌러 ○ 있다 / ✕ 없다 표시)가 있어서, 경우를 줄여 가며 생각하도록 도와요.
- **컴퓨터와 연습**(쉬움 · 어려움 · 4자리)은 포인트 없이, 인터넷 없이도 할 수 있어요.
- 교사 화면 → 반을 고르면 **숫자야구** 칸이 보여요: **켜기/끄기**(끄면 새 경기를 열 수 없고 진행 중인 경기는 그 자리에서 멈춰요. 수업 시간에 꺼 두세요), **최대 판돈**, 학생별 전적과 포인트 손익, 최근 경기.

## 패드 홈 화면에 앱처럼 놓기 (선택)

Safari에서 사이트를 열고 **공유 버튼 → 홈 화면에 추가**를 누르면 아이콘이 생겨요.

## 기록이 꼬이지 않게 하는 장치

- **여러 기기**: 학교 패드와 집 휴대폰처럼 두 기기에서 써도 기록을 덮어쓰지 않고 합쳐요. (진도는 둘 중 더 나아간 쪽, 복습 노트는 둘 다, 포인트는 양쪽에서 받은 만큼 더해요)
- **와이파이가 끊겼을 때**: 기록은 기기에 먼저 저장되고, 다시 연결되면 자동으로 올라가요. 오른쪽 위 번호 옆 점이 초록이면 저장 완료, 노랑이면 저장 중, 빨강이면 아직 못 올린 상태예요.
- **함께 쓰는 패드**: 10분 넘게 쓰지 않다가 다시 열면 "1학년 3반 2번 맞나요?"라고 물어요. 다른 학생이면 「아니요」를 눌러 바로 로그아웃할 수 있어요.

## 교사 화면에서 볼 수 있는 것

- 학급 현황: 최근 접속, 포인트, 연속 일수, 차시별 진도(개념·탐구·단계·연습), 연습 문제 수, 복습 대기, 최근 7일 풀이 수, 잠김 여부
- 번호를 누르면 그 학생의 최근 풀이 30개 (단계별 틀린 횟수 포함)
- **엑셀로 받기**: 지금 보고 있는 반의 표를 CSV 파일로 내려받아요. 엑셀에서 바로 열려요.
- **이번 주 데미지**: 학생별로 이번 주에 보스에게 준 데미지(=이번 주에 받은 포인트). 교사 화면에서만 보여요.
- **많이 막히는 단계**: 단계 문제에서 단계마다 한 번이라도 틀린 비율과, 세 번 틀려 정답을 확인한 비율 (7·30·90일)

## 개인정보와 보안

- 학생 이름은 저장하지 않아요. 학년·반·번호, 비밀번호의 암호화된 값, 학습 기록만 저장합니다.
- 비밀번호를 5번 틀리면 10분 동안 잠겨요 (학생·교사 모두).

- Supabase 무료 플랜은 **일주일 동안 접속이 없으면 서버가 잠듭니다.** 방학 뒤에는 Supabase 대시보드에서 **Restore** 를 눌러 깨우세요.

## 교과서 유형 문제 (지학사 중학교 수학 1, Ⅶ-01)

같이 풀기 · 혼자 풀기에 교과서 문제 유형을 섞었어요. 문제 위 노란 꼬리표에 교과서 쪽수가 나와요.

| 차시 | 유형 | 교과서 |
|---|---|---|
| 다면체 | 몇 면체 · 모서리 · 꼭짓점 구하기 (`polyAll3`) | 211쪽 1번 |
| 다면체 | 보기에서 면의 모양으로 고르기 (`polyFaces`) | 215쪽 3번, 240쪽 1번 |
| 각기둥·각뿔·각뿔대 | 밑면·옆면 모양, 꼭짓점·모서리·면 표 (`typesTable`) | 212쪽 2번 |
| 각기둥·각뿔·각뿔대 | 면의 개수로 각뿔대 찾고 b − a (`typesDiff`) | 215쪽 5번 |
| 각기둥·각뿔·각뿔대 | 뜻 ○× (`typesTF`) | 215쪽 1번 |
| 정다면체 | 정다면체가 아닌 이유 (`regularWhy`) | 214쪽 4번 |
| 정다면체 | 조건 두 개 → 모서리·꼭짓점 개수 (`regularCondCount`) | 240쪽 2번 |

- 예전 생성기(`poly`, `types`, `regular` …)는 그대로 두고 섞은 생성기(`poly2`, `polyStep2` …)를 새로 만들었어요. 복습 노트의 예전 문제도 똑같이 다시 나와요.
- 미리 보기 탭 맨 위에 「미리 보기」 상자(핵심 낱말 4개 + 교과서 예시 하나)를 넣었어요. 정다면체의 두 조건은 정규 수업에서 찾도록 접어 두었어요.
- 전개도 유형(214쪽 더 생각하기, 240쪽 3번)은 아직 없어요.

## 문제 유형 나누기 (유형 학습)

차시마다 교과서 문항을 기준으로 유형 4가지를 정했어요 (`PTYPES`). 유형마다 이름 · 교과서 쪽수 · 「핵심」(푸는 방법 한 줄)이 있어요.

| 차시 | 유형 1 | 유형 2 | 유형 3 | 유형 4 |
|---|---|---|---|---|
| 다면체 | 다면체인지 판단하기 (211쪽) | 몇 면체인지 구하기 (211쪽 1번) | 모서리 · 꼭짓점 세기 (211쪽 1번) | 면의 모양으로 고르기 (215쪽 3번 · 240쪽 1번) |
| 각기둥·각뿔·각뿔대 | 밑면 · 옆면의 모양 (212쪽) | 꼭짓점 · 모서리 · 면의 개수 (212쪽 2번) | 개수를 보고 입체도형 찾기 (215쪽 5번) | 뜻 · 성질 ○× (215쪽 1번) |
| 정다면체 | 정다면체가 아닌 이유 (214쪽 4번) | 조건으로 정다면체 찾기 (213쪽 · 240쪽 2번) | 꼭짓점 · 모서리 · 면의 개수 (214쪽 3번) | 성질 ○× · 옳지 않은 것 (215쪽 1번) |

- **같이 풀기**: 유형 1 → 4 차례로. 문제 위에 유형 이름과 핵심이 펼쳐져 있어요. 「같은 유형 하나 더」 / 「다음 유형 →」.
- **혼자 풀기**: 「유형별」(한 유형만 반복, 핵심은 접어 둠)과 「섞어서」(유형을 숨기고 섞어 풀기 → 푼 뒤에 "이 문제는 유형 ○" 알려 줌). 유형마다 맞힌 개수를 보여 줘요.
- 유형 생성기 `ty_차시_번호`는 기존 생성기에서 그 유형만 골라 내요. 씨앗이 같으면 문제도 같아서 복습 노트에서도 그대로 다시 나와요.
- **미리 보기**: 맨 위 「오늘의 핵심」(2~3줄, 각기둥·각뿔·각뿔대 개수 표, 정다면체 구별 표)을 가장 크게, 그 아래 예시 하나 · 낱말 · 수업 뒤 연습할 유형.

## 2026-11-25 개편: 1차시 합치기 · 유형 고르기 · 카드형 미리 보기

- **1차시 「다면체 · 각뿔대」(교과서 211~212쪽)**: 예전 1차시(다면체)와 2차시(각기둥·각뿔·각뿔대)를 합쳤어요. 정다면체가 2차시, 이후 차시 번호도 하나씩 당겨졌어요. 예전 `#types` 주소로 들어오면 1차시로 가요. 문제 유형은 7가지(다면체인지 판단 · 몇 면체 · 모서리·꼭짓점 세기 · 각뿔대 표 · 개수로 입체도형 찾기 · 면의 모양으로 고르기 · 뜻 ○×).
- **유형 고르기 화면**: 같이 풀기와 혼자 풀기를 열면 먼저 유형 카드가 나와요(대청 수학 「기초 연습」 방식). 카드에는 유형 이름 · 핵심 · 교과서 쪽수 · 푼 기록이 있고, 같이 풀기는 아직 안 푼 첫 유형에, 혼자 풀기는 많이 틀린 유형(2문제 이상, 정답률 60% 미만)에 「추천」이 붙어요. 문제 화면 위 「← 유형 고르기」로 돌아가요. 혼자 풀기의 「유형 섞어 풀기」(`mix_차시`)는 유형을 고르게 섞어요.
- **미리 보기 카드**: 「오늘의 핵심」 카드 3장 + 예시 카드. 누르면 화면 가운데 크게 열려요(TV 시연용). 아래 자세한 개념도 카드 모양이고, 누르면 큰 창으로 열려요(Esc 또는 바깥을 누르면 닫혀요).

## 1차시 유형 5가지 (풀이 절차 기준) · 같이 풀기 풀이 예시 · 그림 미리 보기

- 유형을 교과서 쪽수가 아니라 **풀이 절차**로 다시 나눴어요: ① 무엇인지 가려내기 ② 이름 짓기(2가지) ③ 그림 보고 개수 세기 ④ 이름만 보고 개수 구하기 ⑤ 거꾸로 찾기(모서리가 12개인 다면체 모두 찾기 포함). 새 생성기: `p5family`, `p5name2`, `p5byname`, `p5findAll`.
- **같이 풀기 (나란히 보기)**: 유형을 고르면 **왼쪽에 선생님 풀이**(「풀이 보기 ▶」로 한 단계씩, 「모두 펼치기」), **오른쪽에 같은 모양의 문제**(숫자만 다름)를 학생이 단계별로 풀어요. 학생이 푸는 단계와 같은 왼쪽 단계에 노란 테두리가 따라가요. 짝 문제는 `ptype`·`sig`·단계 구성이 같은 것으로 골라요. 끝나면 「같은 유형 하나 더(왼쪽 풀이 그대로) / 새 풀이 예시로 / 다음 유형」. 좁은 화면(900px 이하)에서는 위아래로 쌓여요.
- **미리 보기(1차시)**: 글 카드 대신 **그림 카드 5장**(다면체일까? · 면·모서리·꼭짓점 · 각기둥·각뿔대·각뿔 · 이름은 두 가지 · 층으로 보기). 누르면 크게 열리고 그림을 돌려 볼 수 있어요. 카드 내용은 `PV_CARDS`에서 고쳐요.

## 수업 중 실시간: 도움 요청 · 학생 현황 (교사 화면)

**처음 한 번**: Supabase 대시보드 → SQL Editor에 `supabase/live.sql`을 붙여 넣고 Run. (새로 설치할 때는 schema.sql에 이미 들어 있어요.) 실행 전에는 교사 화면에 안내 문구가 나오고, 학생 화면의 손들기 단추는 숨겨져요.

- **학생**: 오른쪽 아래 **✋ 선생님 도와주세요** 단추. 누르면 「손 들었어요」로 바뀌고, 선생님이 [도왔어요]를 누르면 내려가요. 학생 화면은 화면을 옮길 때 · 답을 낼 때 · 1분마다 지금 있는 곳(예: `1차시 다면체 · 각뿔대 · 같이 풀기 · 유형 3 · 그림 보고 개수 세기`)을 알려요.
- **교사 화면 · 🙋 지금 도울 학생** (반을 고르면, 10초마다 새로 고침): 손든 학생 · 단계 정답을 보고 넘어간 학생 · 같은 유형 3번 연속 틀림 · 3번 넘게 틀린 끝에 맞힘 · 5분 넘게 답을 내지 않음(문제 화면에서). 위쪽 **함께 볼까요?**: 최근 40분 동안 같은 유형 같은 단계에서 3명 이상(접속 학생의 30% 이상) 막히면 그 단계의 질문과 번호가 떠요. **[✓ 도왔어요]**는 손을 내리고 그때까지의 알림을 숨겨요(새로 막히면 다시 나타남).
- **교사 화면 · 학생 현황 · 오늘**: 번호별 접속 여부, 지금 있는 곳, 오늘 푼 문제 · 처음에 맞힌 문제, 마지막으로 답을 낸 시각, 최근 12문제 점(초록 처음에 맞힘 · 노랑 틀린 뒤 맞힘 · 빨강 틀림/정답 확인).
- 서버 함수: `hg_ping` · `hg_help`(학생), `hg_t_live` · `hg_t_ack`(교사), 표 `hg_live`. 체험 모드(MOCK)에도 같은 함수가 있어요.

## 패드 · 휴대폰 가독성

- **같이 풀기 (900px 이하)**: 왼쪽 풀이 대신, 지금 푸는 단계 바로 위에 「선생님 풀이 · 같은 단계 보기」가 붙어요. 「선생님 풀이 전체 보기」로 전체 풀이를 펼칠 수 있어요.
