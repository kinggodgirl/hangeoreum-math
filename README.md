## 1. Supabase 서버 만들기 (약 10분, 한 번만)

1. https://supabase.com 에 가입하고 **New project** 를 누릅니다.
   - Region: **Northeast Asia (Seoul)** (또는 가까운 아시아 리전)
   - Database password: 긴 비밀번호를 정해 따로 적어 둡니다.
2. 왼쪽 메뉴 **SQL Editor** → **New query** → `supabase/schema.sql` 내용을 모두 붙여 넣고 **Run**.
3. 같은 창에서 아래 한 줄을 실행해 **교사 비밀번호**를 정합니다. (따옴표 안을 바꾸세요)
   ```sql
   select public.hg_setup_teacher('여기에-교사-비밀번호');
   ```
4. **Project Settings → API** 에서 두 값을 복사합니다.
   - Project URL (예: `https://abcdefghijkl.supabase.co`)
   - `anon` / Publishable 키

> 공개 키(`anon` / `sb_publishable_...`)는 프론트에 들어가도 괜찮습니다. 모든 테이블은 RLS로 직접 접근을 막아 두었고, 검증된 RPC 함수로만 동작합니다.
> **secret / service_role 키는 절대 `config.js`에 넣지 마세요.**

## 2. `config.js` 채우기

```js
window.HG_CONFIG = {
  supabaseUrl: 'https://abcdefghijkl.supabase.co',
  supabaseAnonKey: 'sb_publishable_...'
};
```

## 3. GitHub Pages에 올리기

1. GitHub 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**.
2. 1~2분 뒤 `https://<아이디>.github.io/hangeoreum-math/` 로 열립니다.

## 4. 학생 번호 만들기

1. 사이트 맨 아래 **교사 화면** → 교사 비밀번호로 로그인.
2. **학생 관리** → **학생 만들기**에서 학년·반·번호 범위를 정해 생성(방과후 반에서 `1-3-5 김민수` 형식으로 일괄 추가도 가능).
3. 4자리 비밀번호는 생성 직후 한 번만 보입니다. **목록 복사** 또는 **카드로 보기 → 인쇄**로 나눠 주세요.
4. 비밀번호를 잊은 학생은 표의 **비밀번호** 버튼으로 새로 발급하세요.

## 기초 연산 (28개 주제 · 5갈래 사다리 · 연결맵)

기초학력 학생을 위해 미국 교육부 IES 실천 지침(체계적·명시적 지도, 구체물·그림, 수직선, 유창성, 누적 복습)과 인출 연습·간격 반복 근거로 설계했습니다.

| 사다리 갈래 | 주제 (`CALC`) |
|---|---|
| 🔢 수 감각 | 자릿값, 덧셈·뺄셈(10 만들기), 두 자리 덧셈·뺄셈, 곱셈구구(36칸 유창성 표), 나눗셈, 나머지 나눗셈, 곱셈 감각, 어림하기 |
| 🧩 식 다루기 | 계산 순서, 식에 수 넣기, 거꾸로 풀기, 겉넓이 더하기 |
| 🍕 분수 · 소수 · 비 | 분수의 뜻, 대분수와 가분수, 약수·배수 기초, 분수 곱하기, 분수 더하기·빼기, 분수 나누기, 분수와 소수 바꾸기, 소수 계산, 비 간단히 하기 |
| 📐 도형 계산 | 제곱수와 세제곱수, 넓이 공식, π가 있는 계산(5단계), 단위 바꾸기 |
| ➕ 정수와 부호 | 부호가 있는 덧셈, 부호가 있는 뺄셈, 부호가 있는 곱셈·나눗셈 |

* **연결맵(`CALC_PRE`)**: 28개 주제의 41개 바탕 관계를 지도로 보여 줍니다. **시험 모드(기본 켜짐)** 에서도 막힌 주제가 있으면 바탕 칸을 **바탕 다지기**로 자동 열어 줍니다.
* **오늘의 계산**: 5문제/10문제 모드, 간격 반복(1·2·4·7·14일) + 구구단 + 바탕 주제를 섞어 냅니다.
* **오개념 진단**: 틀린 답을 보고 실수 원인을 짚어 주며, `DB._calcErrs`에 누적해 교사 화면에서 확인할 수 있습니다.

## 게임 · 보상 · 오프라인 연계

* **행동 기반 포인트 보상**: 맞힌 개수뿐 아니라 *끝까지 완료(+4/+6)·틀린 문제 다시 맞히기(+2)·첫 도전(+3)·별 획득(+5)* 등 과정에 포인트를 주며 받을 때 이유를 함께 표시합니다.
* **오늘의 미션**: 하루 3개 미션 완료 시 보너스 포인트 및 연속 학습일(`days`) 기록.
* **꾸미기 상점 (`js/04-games.js`)**: 모은 포인트는 그대로 두고 가용 포인트로 **Kenney 3D 미니 캐릭터 12종 · 3D 모자 6종 · 프로필 프레임 · 형광펜**을 구매하거나 **착한 캡슐 뽑기**(포인트 뽑기 중복 없음, 오늘의 계산 완료 시 하루 1회 무료권)를 이용할 수 있습니다.
* **우리 반 보스전 / 1:1 숫자야구**: 반 협동 보스전(개인 순위 없음)과 서버 검증 1:1 숫자야구, 컴퓨터 연습 지원.
* **A4 점검 학습지 & 폰 사진 OMR 채점 (`#print`, `#scan`)**: 단원/차시별 시험지 인쇄 및 학생 자가 OMR 촬영 채점 → 교사 화면 자동 집계.
